Privacy Policy — YouTube Uploader

Last updated: 24 November 2026

This policy covers the private application used to publish videos from this site to the operator's own YouTube channel. It is not a public product and has no other users.

What the application accesses

  • The youtube.upload scope only. It creates videos on the channel it is authorised for.
  • It does not read your watch history, subscriptions, comments, or any other channel data.
  • It cannot delete, edit or moderate existing videos.

What is stored

  • An OAuth refresh token, stored in a local file on the operator's own computer.
  • That token is never sent to this website, to any server we run, or to any third party.
  • No analytics, no profiling data, and no personal data about viewers is collected by the application.

Data sharing

Nothing is shared. The application has no backend service; it talks directly from the operator's machine to Google's API endpoints.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local token file removes the stored credential immediately.
